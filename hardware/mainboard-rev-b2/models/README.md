# Installed package geometry

Models are in millimetres at the footprint-local mounting datum. KiCad orients and mirrors instances on the back face. The populated STEP adds KiCad’s nominal 0.05 mm body standoff. Library STEP models retain their distributed headers. [KiCad library sources and license](../../../THIRD_PARTY_NOTICES.md).

The CPG151101S11-16 model follows the offset contact pockets, PCB locating bosses, shell outline and solder tails. SK6812MINI-E-Rev02 models the optical body extending into the PCB aperture with four solder tabs. PEC11R-4220F-S0024 includes the body, ground tabs, five terminals, bushing and D-shaft. SOIC-8W is a nominal package envelope for U2. These four project models support interference checks. Articulated internal contacts and cosmetic features are simplified.
